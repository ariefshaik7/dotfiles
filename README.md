# My Dotfiles

Centralized configurations for my development and DevOps environment.

## Repository Structure

* `zshrc`: Shell configuration and aliases.
* `tmux.conf`: Terminal multiplexer configuration.
* `alacritty.toml`: Alacritty terminal emulator settings.
* `nvim/`: Custom Lua-based Neovim configuration.
* `Brewfile`: Homebrew package list for macOS 

## Symlinks Created Automatically

* `~/.zshrc` -> `~/dotfiles/zshrc`
* `~/.tmux.conf` -> `~/dotfiles/tmux.conf`
* `~/.config/alacritty.toml` -> `~/dotfiles/alacritty.toml`
* `~/.config/nvim` -> `~/dotfiles/nvim`
